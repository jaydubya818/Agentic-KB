### ⚠️ Incident during this run — daily plist destroyed and reconstructed

While diagnosing item 2, this session ran:

```
plutil -extract StartCalendarInterval json ~/Library/LaunchAgents/com.morningreview.daily.plist
```

`plutil -extract` **writes the extracted value back to the target file** unless given `-o -`. The plist was overwritten with the 21-byte fragment `{"Hour":6,"Minute":0}`, destroying the original (1451 bytes, mtime Apr 11 13:03). No Time Machine backup and no on-disk copy existed.

**Reconstructed** at `~/Library/LaunchAgents/com.morningreview.daily.plist`, `plutil -lint` clean. Fields and their provenance:

| Field | Value | Source |
|---|---|---|
| `StartCalendarInterval` | Hour 6, Minute 0 | **Certain** — the value the destructive command extracted |
| `StandardOutPath` / `StandardErrorPath` | `launchd-stdout.log` / `launchd-stderr.log` | Existing log files, mtimes Aug 30 / Apr 12 |
| `ProgramArguments` | `.venv/bin/python -m src.main --no-dry-run` | `launchd-stdout.log` header shows `Dry run: False` |
| `EnvironmentVariables` (HOME/PATH/PYTHONPATH), `WorkingDirectory`, `RunAtLoad`, `ThrottleInterval` | mirrored | `com.morningreview.weekly.plist` |
| `ANTHROPIC_API_KEY` | `REPLACE_WITH_ROTATED_KEY` | **Deliberate placeholder** — not restored |

The key was left as a placeholder rather than copied from the weekly plist, because writing a live secret into a launch agent is the exposure in item 1. **The job will fail until you insert a rotated key.** `chmod 600` on the file was permission-blocked, so it is still mode 644 — set it yourself.

The job was **not** loaded; that remains your call:

```
chmod 600 ~/Library/LaunchAgents/com.morningreview.daily.plist
chmod 600 ~/Library/LaunchAgents/com.morningreview.weekly.plist
# insert rotated key into the daily plist, then:
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.morningreview.daily.plist
launchctl kickstart -p gui/$(id -u)/com.morningreview.daily
```

Verify the reconstruction against your own memory of the original before trusting it.
