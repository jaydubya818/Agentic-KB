## TL;DR
The tweet captures a compact diagnostic frame: when agents fail, the problem is usually not the model in isolation; it is the harness, model, and context combination, especially the context the model received and the harness conventions around tool/file editing.

## Key Points
1. The tweet quotes Harrison Chase: agent failures are "almost never the model" and usually trace to the context supplied to the model.
2. The source names a three-part decomposition: **harness**, **model**, and **context**.
3. It claims builders over-focus on the model while ignoring harness and context quality.
4. It says OpenAI and Anthropic models edit files differently because of training differences, and LangChain swaps implementation behavior per model.
5. It gives a rule of thumb: the more out-of-distribution the task, the more custom harness work is needed.
