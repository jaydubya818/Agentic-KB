WORKDAY TECHNICAL CONCEPTS — INTEGRATIONS & REPORTING
Before the talking scripts, understand the core technologies Austin may ask you to explain.
1. WHAT IS EIB?
EIB = Enterprise Interface Builder
EIB is a Workday integration tool used to configure relatively straightforward inbound and outbound data exchanges.
Inbound EIB: Loads data into Workday using supported operations.
Outbound EIB: Extracts Workday data and sends it to an external destination.
Example: Importing employee-related information into Workday or exporting employee information to a benefits provider.
Key components:
Data Mapping
Supported Web Service Operations
Custom Reports
Integration System Security
Integration Events
Error Handling
Data Reconciliation
2. WHAT IS WORKDAY STUDIO?
Workday Studio is a development environment for building more complex integrations.
It supports data transformations, orchestration, conditional logic, and more sophisticated integration processing.
Example: Processing employee data from multiple systems, transforming it, applying validation logic, and delivering it to a downstream provider.
Simple distinction:
EIB = Simpler Data Exchange
Studio = Complex Integration Logic
3. WHAT ARE WORKDAY APIs?
API = Application Programming Interface
Workday provides APIs and web services that allow authorized external applications to interact with Workday data and business operations.
Common integration approaches include:
SOAP Web Services: Workday operations for retrieving and updating supported business objects.
REST APIs: Supported endpoints for programmatic access to Workday functionality.
RaaS — Reporting-as-a-Service: Exposes eligible Workday reports as web-accessible data sources.
Core Connectors: Workday-supported integration frameworks for common integration patterns.
4. WHAT ARE CALCULATED FIELDS?
Calculated fields derive information using Workday business objects and related data.
Common examples include:
Lookup Related Value (LRV): Retrieves a value from a related business object.
Evaluate Expression: Returns a value based on defined conditions.
Extract Single Instance (ESI): Selects one instance from a collection.
Extract Multi-Instance (EMI): Returns multiple instances based on defined criteria.
Example: A workforce report needs to display an employee’s manager, supervisory organization, and location.
Calculated fields can help retrieve or derive information that isn’t directly available from the selected report data source.
